# Hostel Event Volunteer Manager

A simple Python-based project for managing volunteers for hostel events.

## Features

- Add volunteer details
- Store volunteer information
- Manage event-related volunteer data
- Display volunteer details

## Technologies Used

- Python
- Visual Studio Code
- Git and GitHub

## How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python volunteer_management.py
